# Changelog

## 0.1.0

- Matrix-based rooms, invitation / join, plaintext text messages, native replies, history pagination and synchronization with cursor recovery.
- Passwordless managed identities through a registered Application Service, using separate ordinary user sessions.
- Multi-room local web UI, multiple Agent identities, member invitation, manual reply selection and human-directed message handoff.
- Harness Dock host example with sender authorization, persisted run receipts, original-run observation and recoverable reply delivery. A detached host process preserves the application connection across web backend restarts.
- Independent local setup using Docker, with bundled PostgreSQL or an existing shared Docker database; persistent data and separate non-admin application account.
- CLI identity profiles, no-model diagnosis, SDK build / local packaging, deployment and integration documentation.

Delivery is source pushed to the existing private repository. No public repository conversion, npm publication, public Release or X post is part of this delivery.
